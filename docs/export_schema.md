# Спецификация таблицы наблюдений (схема 1.1)

Одна строка = одно наблюдение одного объекта в одном кадре. Уникальный ключ: `experiment_id, sequence_id, track_id, frame`.

Дополнительные условия эксперимента добавляются столбцами `cond_<имя>` (значения берутся из конфигурации, одинаковы для всех строк).

Типы: `str` — строка, `int` — целое без пропусков, `Int` — целое с возможными NA, `float` — вещественное, `bool` — логическое. NA в CSV — пустая ячейка.


## ключи

| Столбец | Тип | Единица | NA | Описание |
|---|---|---|---|---|
| `experiment_id` | str | — | нет | Идентификатор эксперимента (из конфигурации) |
| `sequence_id` | str | — | нет | Идентификатор видео/последовательности кадров |
| `track_id` | int | — | нет | Устойчивый идентификатор объекта в пределах последовательности (с 1) |
| `frame` | int | — | нет | Номер кадра в исходной последовательности (не в обработанной) |
| `timestamp_s` | float | s | нет | Время кадра от начала записи, с |

## положение

| Столбец | Тип | Единица | NA | Описание |
|---|---|---|---|---|
| `x_px` | float | px | нет | Координата центроида X (вправо), px |
| `y_px` | float | px | нет | Координата центроида Y (вниз), px |
| `x_um` | float | µm | да | X в микрометрах; NA без калибровки |
| `y_um` | float | µm | да | Y в микрометрах; NA без калибровки |

| Столбец | Тип | Единица | NA | Описание |

| `dt_s` | float | s | да | Интервал до предыдущего наблюдения трека, с; NA у первого наблюдения |

| `displacement_px` | float | px | да | Смещение центроида от предыдущего наблюдения; NA у первого |
| `displacement_um` | float | µm | да | То же в µm; NA без калибровки или у первого |
| `speed_px_s` | float | px/s | да | Скорость = смещение / dt; NA у первого или при dt <= 0 |
| `speed_um_s` | float | µm/s | да | Скорость в µm/с; NA без калибровки |
| `direction_deg` | float | deg | да | Направление движения, ось Y вниз (+90° — вниз); NA при нулевом смещении |

## Проверки при экспорте (`validate_table`)

1. Присутствуют все столбцы схемы; типы совпадают с таблицей выше.
2. Пустые значения только в столбцах с NA = да; нет `inf`.
3. Ключ уникален; в треке `frame` и `timestamp_s` строго возрастают.
4. Диапазоны: доли и уверенности в [0, 1], `aspect_ratio` >= 1, площади и длины > 0.
5. Единицы: µm-столбцы пусты без калибровки и равны px-столбцам × `um_per_px` (в степени 2 для площади) при калибровке.
6. `track_n_obs` совпадает с числом наблюдений трека в таблице.
