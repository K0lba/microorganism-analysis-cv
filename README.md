# Microorganism Analysis CV (`microtrack`)

Офлайн-обработка микроскопических видео и кадров с микроорганизмами:
найти клетки (сегментация), проследить их между кадрами (трекинг), измерить форму
и движение (морфометрия, динамика) и выгрузить таблицу наблюдений для Модуля 1.

```
видео / кадры → предобработка → сегментация → трекинг → морфометрия и динамика → таблица CSV / Parquet / DataFrame
                                (classical или                                   + сводка по трекам
                                 готовая модель)                                 + видео с наложением
```

Сегментация, трекинг и измерения — независимые модули: алгоритм сегментации
меняется одним параметром, остальной конвейер не трогается.

## Установка

Python 3.10+. Из корня проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

`requirements.txt` ставит и готовые модели (torch, Cellpose, Omnipose, StarDist, SAM 2).
Для одного классического конвейера достаточно `pip install -e .`.

## Быстрый старт

Все команды — из корня проекта; `tasks.ps1` сам подхватывает `.venv`
(`make` в Windows обычно нет, `Makefile` — обёртка над ним).

```powershell
.\tasks.ps1 help                                    # список целей
.\tasks.ps1 test                                    # все тесты
.\tasks.ps1 demo                                    # синтетическое видео → results/demo/
.\tasks.ps1 video -Source video.mp4                 # своё видео → results/video/
.\tasks.ps1 video -Source frames\ -Fps 5 -PixelSizeUm 0.1 -Model sam2_auto
.\tasks.ps1 morphology -Image frame.png             # один кадр без трекинга
```

Без `tasks.ps1`:

```powershell
python scripts/run_video.py video.mp4 --out results/run1 --fps 5 --pixel-size-um 0.1 `
    --model sam2_auto --condition medium=PBS --condition temperature_c=37
```

Источник — видеофайл, папка с кадрами, многостраничный TIFF или одно изображение.

## Что получается на выходе

Каталог `results/<имя>/`:

| Файл | Содержимое |
|---|---|
| `observations.csv`, `.parquet` | одна строка = один объект в одном кадре: ID трека, время, положение, скорость, площадь, длина, ширина, форма, качество сегментации и трекинга, калибровка, условия `cond_*` |
| `tracks_summary.csv` | итоги по каждому треку: длительность, путь, средняя/медианная/максимальная скорость, прямолинейность |
| `overlay.mp4`, `preview.png` | маски, ID и траектории поверх кадров; красный контур — сомнительная сегментация, `?` — неоднозначное сопоставление, крестик — объект пропал |
| `run.json` | параметры запуска, число кадров и треков, результат проверки таблицы |

Полная спецификация столбцов: [`docs/export_schema.md`](docs/export_schema.md).
Перед записью таблица проверяется (`export.validate_table`): типы, пропуски,
уникальность ключа, возрастание времени, диапазоны, согласованность px и µm.

Без калибровки µm-столбцы пустые, размеры — в пикселях. Время берётся из отметок
кадров, а не из номера обработанного кадра, поэтому скорость не зависит от `--stride`.

## Конфигурация

`configs/default.yaml`: секции `input` (шаг кадров, источник времени, fps),
`preprocessing`, `segmentation` (`method: classical` или имя модели), `tracking`,
`calibration`, `experiment` (ID и условия), `output`. Флаги `run_video.py`
переопределяют конфиг. Свой конфиг: `--config my.yaml`.

## Модели сегментации

| `--model` | Что это | Когда брать |
|---|---|---|
| `classical` | порог Otsu/адаптивный + морфология | контрастные кадры, быстро (мс на кадр) |
| `sam2_auto` | SAM 2.1, автоматические маски | неоднородный фон, фазовый контраст |
| `cellpose_cpsam`, `cellpose_cyto3` | Cellpose | клетки на однородном фоне |
| `omnipose_bact_phase` | Omnipose | бактерии, фазовый контраст |
| `stardist_fluo` | StarDist | яркие ядра на тёмном фоне (флуоресценция) |

Веса Cellpose, Omnipose и StarDist скачиваются при первом запуске. SAM 2 берётся
с Hugging Face или из локального файла: `weights\models\sam2.1_hiera_small.pt`
`tasks.ps1` подставит сам, иначе — переменная `SAM2_CHECKPOINT`. На CPU готовые
модели считают секунды–минуты на кадр; для пробы — `-MaxFrames 3`.

## Проверка качества

Реальной разметки пока нет, поэтому корректность проверяется на синтетике с
известными масками, траекториями и размерами:

- `tests/` — метрики, морфометрия на фигурах с известной геометрией, трекинг с
  известными ID, динамика при разных интервалах, экспорт и сквозной конвейер;
- `scripts/benchmark.py` — IoU, Dice, F1 классических алгоритмов по сценариям
  (шум, освещение, слипание, контраст) → `results/benchmark_*.csv`;
- `scripts/compare_models.py` — то же для готовых моделей, плюс время и память.

```
  temporal.py             время, скорость, калибровка, относительные изменения
  export.py               схема, проверка и запись таблицы
  visualization.py        наложение масок, ID и траекторий
  pipeline.py             сквозной конвейер
tests/
```

## Известные ограничения

- Классическая сегментация сливает соприкасающиеся клетки (цепочки, диплококки)
  в одну маску; экспериментальное разделение — `segmentation.split.enabled: true`.
- Трекер не моделирует деление и слияние клеток; предсказание — постоянная скорость.
- Маски хранятся в полный размер кадра: сотни объектов на большом кадре — сотни МБ памяти.
- Готовые модели проверены только на синтетике; на реальных снимках нужна разметка
  и повторная оценка.
